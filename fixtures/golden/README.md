# Golden files

Generated by `pnpm goldens` (`scripts/make-goldens.mjs`) by running the artifact's own code
(`scripts/artifact.mjs` extracts each tab's code from `fixtures/okladzina-domu.html`).

* `salon.json`, `sypialnia.json`, `lazienka-1.json`, `lazienka-2.json`: per room, the default input, 20 seeded random valid
  inputs and 3 deliberately out-of-range inputs (`clamp1..3`). For each case: `norm` (clamped params + warnings),
  `model` (JSON of the model, functions dropped), `pieces` (`cutPieces`), `shelf` (the per-room shelf packer),
  `svg` (size + SHA-1 of the plan/boards/gables/sheet SVGs; full text in `svgText` for the default case).
* `shared.json`: 16 configurations of the shared cut (`compute()` of the "Wspólny rozkrój" tab): per-room pieces, band, price,
  split flag, and the full result (plates with item positions, statistics). The artifact's search is time boxed;
  the generator refuses cases where it stopped before the 2000 tries, so the goldens are machine independent.

Generation is deterministic (seeded). Do not edit by hand.
